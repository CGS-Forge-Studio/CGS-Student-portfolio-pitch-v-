# CGS HUB — Student Portfolio

The standalone Student Portfolio frontend runs without the separate Attendance prototype project.

## Run locally

- `npm run dev` starts the portfolio at `http://localhost:3000` and opens it in your default browser.
- The frontend is in `frontend/` and uses sample demo data stored in its own app source/browser storage.
- `npm run dev:api` can start the optional NestJS API when `CGS-Attendance-prototype-main` is present beside this workspace. The portfolio demo does not require it.

The demo login is available from the sign-in screen. Use “Continue with demo account” to explore the overview, attendance, academic record, achievements, and digital vault.
